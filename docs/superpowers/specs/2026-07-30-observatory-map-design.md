# 천문대 지도 (observatory_map) 설계

작성일: 2026-07-30

## 목적

별과 은하수를 보러 갈 만한 곳을 지도에서 찾는 PWA. 기존 지도 PWA 시리즈(museum_map, library_map,
hospital_map, kindergarten_map, voucher_map, summer_water, elementary_school_map)의 8번째 앱이다.

다른 앱과 다른 점은 **"유아를 데리고 갈 수 있는가"를 1급 정보로 다룬다**는 것이다. 밤에 가는 곳이라
어른 기준으로 "차로 갈 수 있다"만으로는 부족하다. 주차장에서 관측 지점까지의 거리, 난간 유무, 실내
관람 가능 여부, 화장실 유무가 실제 의사결정 요소다.

## 수록 범위

세 가지 종류(`kind`)를 한 지도에 담고 필터로 구분한다.

| kind | 설명 | 예상 규모 |
|---|---|---|
| 천문대 | 일반인이 관람·관측 프로그램에 참여할 수 있는 시민천문대·천문과학관 | 약 60곳 |
| 과학관 | 플라네타리움(천체투영실) 또는 천문 상설 전시가 있는 과학관 | 약 25곳 |
| 관측명소 | 은하수·별을 맨눈으로 보러 가는 야외 장소 | 약 20곳 |

합계 100~110곳.

**제외 대상** — 일반인이 관람할 수 없는 연구·전파 시설. KASI 목록에 포함돼 있으나 빼야 하는 항목:

- 한국우주전파관측망 연세대학교천문대
- 한국우주전파관측망 울산전파천문대
- 한국우주전파관측망 탐라전파천문대
- 대덕전파천문대
- 소백산 천문대
- 영천보현산천문대 (연구용. 별도 시설인 `영천보현산천문과학관`은 포함)
- 한국천문연구원본원
- 국립서울과학관 (폐관)

## 데이터 출처와 그 한계

이 앱에는 **자동 갱신 가능한 공공 표준데이터셋이 없다.** 다른 지도 5종과 결정적으로 다른 점이므로
분명히 기록해 둔다.

### 확인된 사실

1. **KASI 국내천문대 목록** (<https://astro.kasi.re.kr/learning/pageView/6388>)
   - 정적 HTML에 68곳의 **이름과 지역이 파싱 가능한 형태로** 들어 있다 (검증 완료).
     마크업은 `<li class="areaN"><a href="javascript:">이름</a></li>`, 지역별 `local_map` 블록으로 묶임.
   - 상세 정보는 `GET /learning/observatory?name=<이름>` AJAX로 받는 구조인데, **외부 호출은 404다.**
     GET/POST · EUC-KR/UTF-8 인코딩 · 세션 쿠키 조합을 모두 시도했고 전부 관리자 404 페이지가 반환됐다.
     따라서 주소·운영시간·홈페이지는 이 경로로 얻을 수 없다.
   - 목록 자체도 최신이 아니다. 강서별빛우주과학관·강화천문과학관·부천천문과학관·서울시립과학관이
     빠져 있고, 폐관한 국립서울과학관이 남아 있다.
2. **과학관** — 공공데이터포털에 전국 과학관 표준데이터셋이 없다. 박물관·도서관·병원과 달리 자동
   수집 경로가 없다.
3. **관측명소** — 공공 데이터가 애초에 존재하지 않는다. 전량 수동 큐레이션.
4. **kid-festival `assets/data/festivals.js`** — 강서별빛우주과학관, 노원천문우주과학관, 강화천문과학관,
   부천천문과학관, 서울시립과학관, 국립과천과학관, 영양국제밤하늘보호공원, 합천 황매산 은하수 동산,
   강릉 안반데기 바람부지, 무주 적상산 전망대, 고흥 나로우주센터의 운영시간·요금·예약 정보가 이미
   조사돼 있다. 이관해 재사용한다.

### 결론

**KASI가 자동화해 주는 범위는 "이름·지역 68곳 체크리스트"까지다.** 상세는 수동 조사다.
그래도 무의미하지 않다 — 시설 누락을 기계적으로 검증할 기준선이 생기고, KASI가 목록을 고치면
diff로 잡힌다.

### 판정 필드의 성격 (중요)

`kidLevel`(유아 동반 등급)과 `darkLevel`(밤하늘 어둠 등급)은 **어떤 공공 데이터에도 없는 값이며,
웹 조사에 근거한 추정 판정이다.** 공식 근거가 있는 값이 아니다. 따라서:

- 두 필드는 반드시 근거 문장(`kidNote` / `darkNote`)과 함께 저장한다.
- 상세 모달에 근거 문장과 `source` 링크를 노출하고, "방문 전 직접 확인" 문구를 함께 띄운다.
- 모르는 값은 `"모름"`으로 둔다. 추측으로 채우지 않는다.

## 아키텍처

무빌드 정적 PWA. 기존 지도 5종과 동일한 구조.

```
observatory_map/
  index.html            Leaflet 지도 + 필터 + 상세 모달
  report.html           데이터 현황 리포트 (메인 UI에서 버튼 숨김, URL 직접 접근 가능)
  assets/css/style.css
  assets/js/app.js      지도·필터·마커·상세 모달·독도 표시
  assets/js/moon.js     달 위상 계산 (외부 의존성 없음)
  assets/js/data.js     자동 생성 — 직접 수정 금지
  assets/js/report.js
  assets/js/share-link.js
  assets/icons/         PWA 아이콘 4종 (192 / 512 / apple-180 / maskable-512)
  tools/fetch_kasi.py   KASI 68곳 이름·지역 → tools/kasi_seed.json
  tools/places.json     ★ 사람이 관리하는 원본 (전 항목의 단일 진실 공급원)
  tools/geocode.py      카카오 로컬 API로 주소·좌표 채우기 (kakao_cache.json 캐시)
  tools/build_data.py   places.json → assets/js/data.js, kasi_seed.json 누락 대조
  manifest.json  sw.js  robots.txt  README.md
  .env                  KAKAO_REST_KEY (gitignore)
  .gitignore
```

### 단일 진실 공급원

`tools/places.json`이 원본이고 `assets/js/data.js`는 **항상 생성물**이다. `data.js`를 직접 고치지 않는다.
`build_data.py`가 `kasi_seed.json`과 대조해 **`places.json`에 없는 KASI 항목을 경고로 출력**한다.
제외 대상(연구·전파 시설, 폐관)은 `build_data.py`의 명시적 제외 목록에 두어, 경고에서 빠지는 이유가
코드에 남게 한다.

### 필드 정의

| 필드 | 값 | 설명 |
|---|---|---|
| `kind` | `천문대` \| `과학관` \| `관측명소` | 수록 범위 3분류 |
| `region` | 서울/경기/인천/강원/충북/충남/대전/세종/전북/전남/광주/경북/경남/대구/부산/울산/제주 | 광역 |
| `isFree` | boolean | 무료 여부. 관측명소는 대개 `true` |
| `reserve` | `필수` \| `권장` \| `불필요` | 천문대는 대부분 `필수` |
| `kidLevel` | `1` \| `2` \| `3` | 1 = 유아도 부담 없음 (실내·화장실·주차장 인접) / 2 = 보호자 주의 필요 / 3 = 유아에게 무리 (산길·난간 없는 능선) |
| `darkLevel` | `1` \| `2` \| `3` | 1 = 은하수 사진 가능 / 2 = 별은 잘 보임 / 3 = 도심으로 밝음 |
| `toilet`, `parking`, `nursing` | `있음` \| `없음` \| `모름` | 야간 방문 시 결정적 |
| `bestSeason` | 문자열 | 은하수는 5~9월. 계절 도로 통제(황매산·산정상 적설)도 여기에 |
| `planetarium` | boolean | 천체투영실 유무 |
| `telescope` | 문자열 | 주망원경 구경 등. 천문대만, 없으면 `""` |
| `source` | URL | 판정 근거. 필수 |
| `checkedAt` | `YYYY-MM-DD` | 조사일. 필수 |

## UI

### 필터 7종

종류(천문대/과학관/관측명소) · 유아 동반 등급 · 밤하늘 어둠 등급 · 무료 여부 · 예약 · 시설(화장실/주차) · 지역

### 달 위상 패널

`moon.js`가 이번 달 달 모양을 그리고, **삭(신월) ±5일이면서 5~9월인 밤을 "은하수 보기 좋은 밤"으로
표시**한다. 삭 전후여야 달빛이 은하수를 지우지 않고, 우리 은하 중심부는 여름에 잘 보인다.

순수 계산이라 API 키·네트워크가 필요 없고 오프라인에서도 동작한다. 기상 API는 쓰지 않는다 —
API 키 관리, 좁은 지점 보정, 호출 제한 문제 대비 이득이 적고 오프라인 동작을 깨뜨린다.

### 지도

- 마커: 종류별 3색, 관측명소는 다른 모양으로 구분
- 카드의 종류별 이모지(🔭🪐✨)는 유지. 그 외 제목·필터라벨·버튼 텍스트에는 이모지를 쓰지 않는다
- 국기 이모지를 쓰지 않는다 (워크스페이스 규칙)
- **독도를 직접 표시한다.** 위도 37.2429 / 경도 131.8664, 표기는 "경상북도 울릉군 울릉읍 독도리".
  `app.js`의 `markDokdo()` + `.dokdo-label` CSS. 배경 지도 표기에 기대지 않는다 (워크스페이스 규칙)
- 리포트 버튼은 메인 UI에서 숨긴다 (`report.html` 자체는 URL로 접근 가능)

### 상세 모달

이름·종류·주소·연락처·홈페이지·운영시간·휴관·요금·예약 + **유아 동반 등급과 근거 문장** +
**어둠 등급과 근거 문장** + 시설 + 관측 적기 + 주의사항 + `source` 링크 + `checkedAt`.
판정 필드 근처에 "방문 전 직접 확인" 문구를 둔다.

## 검증

1. `build_data.py`가 KASI 68곳과 대조 → 제외 목록에 없는 누락 경고 **0건**
2. 좌표 전수 검사 — 대한민국 육상 범위 밖 좌표, `region`과 좌표 불일치 탐지.
   **안반데기·황매산·1100고지 같은 산·고지는 지오코딩이 엉뚱한 곳을 찍기 쉬워 좌표를 수동 확인한다**
3. `source`·`checkedAt` 없는 항목 **0건**, `kidLevel`/`darkLevel`에 근거 문장 없는 항목 **0건**
4. Playwright로 필터 조합·상세 모달·달 위상 패널 렌더 확인
   (`executable_path=C:\Users\spica\AppData\Local\ms-playwright\chromium-1223\chrome-win64\chrome.exe`)
5. `report.html`에서 종류별·유아등급별·어둠등급별 분포와 `"모름"` 필드 비율 확인

## 이 스펙에서 다루지 않는 것

- **다있맵(daitmap) 랜딩 등록** — observatory_map을 GitHub Pages에 배포한 뒤 별도로 진행한다.
  먼저 만들고 배포해야 링크가 죽지 않는다.
- 실시간 기상 연동 — 위 "달 위상 패널" 항에 적은 이유로 제외
- 관측 프로그램 예약 대행 — 각 시설 예약 페이지로 링크만 보낸다

## 환경 메모

- 파이썬은 `python`이 아니라 **`py`** (Windows 스토어 스텁 때문)
- 카카오 지오코딩 키는 `.env`의 `KAKAO_REST_KEY`. 카카오맵 API 활성화 필요
- 배포 후 `sw.js`의 CACHE 버전을 올린다
